## How to finish the integration

1. Install dependencies

```bash
npm install
```

2. Install all Untitled UI free components using their CLI

```bash
npx untitledui@latest init untitled-ui --vite
```

3. Start dev server

```bash
npm run dev
```

After CLI import, your components will be copied into your `src/components` directory for immediate use.
